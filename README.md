# Forever Quest (playable prototype build)

Play: https://jonishua.github.io/ForeverQuest-play/

This repo holds only the static web build of a private project by Deep Forest Labs. It is a work-in-progress prototype; source is not here.
Built from commit 69ab885.

Controls (keyboard and mouse, or an Xbox pad): WASD move, right-drag turn the camera, left click or F attack, 1-4 abilities, Space jump, Shift dodge, Tab target.
